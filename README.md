# Kids Games

Three little browser games. No install needed.

**To play:** unzip the folder, then double-click `index.html` and pick a game.

| Game | What it is | Controls |
| --- | --- | --- |
| Gorp's Rainbow Toots | A green monster eats colorful trash and toots or plops out rainbows. | Arrow keys or drag; Z = toot, X = plop |
| Moonmeadow Ranch | Raise unicorns, grow crops, win the Sparkle Show. | WASD to walk, click nearby things, Esc for menu |
| Purple Sparkle Castle | A glittery 3D block castle to explore and build in. | WASD + mouse, click to break, right-click to build |

Notes:
- Fonts and the castle's 3D library load from the internet, so play with a connection.
- Purple Sparkle Castle needs a computer with a mouse. The other two also work on tablets and phones.
- Progress and high scores are saved in the browser you play in.
